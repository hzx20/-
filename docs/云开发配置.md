# 云开发配置指引

云开发是微信提供的后端能力：**不用买服务器、不用备案域名、不用运维**。
对个人开发者来说，它把上线成本从"几千元 + 几天"降到"0 元 + 一小时"。

**重要：不配也能用。** 本项目的所有功能（刷题、判分、错题本、数据统计）
在纯本地都能正常工作。云开发只用来做两件事：

1. 备份答题记录（用户换手机后能恢复）
2. 让开发者能在后台看到数据（用户量、题量、留存）

所以这一步是可选的，不影响先上架。

---

## 一、开通云开发

1. 打开微信开发者工具，导入本项目
2. 工具栏点「云开发」图标
3. 弹出的面板里点「开通」
   - 选「按量计费」或基础版免费额度
   - 实名认证（个人主体用自己的身份证）
4. 开通后在「设置」→「环境设置」里找到**环境 ID**
   - 形如 `jiaozi-shuati-1a2b3c4d`
5. 复制这个环境 ID

> **命名建议**：环境名就是云开发里显示的名字，建议也起成"教资刷题"相关的名字。
> 一个账号可以建多个环境，但免费额度是共用的，个人项目建一个就够。

---

## 二、填入项目配置

打开 `miniprogram/config/index.js`，把 `cloudEnv` 改成你的真实环境 ID：

```js
const cloudEnv = 'jiaozi-shuati-1a2b3c4d';   // ← 改成你的
```

改完这一处，全站的云调用就自动启用了。
`core/cloud.js` 里检测到还是 `'your-env-id'` 时会跳过初始化，
跑纯本地模式，不会报错。

---

## 三、创建数据库集合

云开发控制台 →「数据库」→ 新建集合，需要建两个：

### 集合 1：`users` —— 用户表

字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `_openid` | string | 自动带的，用户唯一标识 |
| `unionid` | string | 开放平台 unionid，可为空 |
| `appid` | string | 小程序 appid |
| `registerAt` | number | 注册时间戳 |
| `lastLoginAt` | number | 最后登录时间戳 |
| `loginDays` | number | 累计登录天数 |
| `totalAnswered` | number | 累计做题数 |
| `totalCorrect` | number | 累计答对数 |
| `totalScore` | number | 累计得分 |

**建议给 `_openid` 建索引**（集合 → 索引管理 → 单字段索引），
否则数据量大了以后每次查询都要全表扫描。

### 集合 2：`answers` —— 答题记录表

字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `_openid` | string | 自动带的 |
| `userId` | string | 冗余存储，方便查询 |
| `questionId` | string | 题目 id |
| `subject` | number | 科目代号 1/2 |
| `correct` | boolean | 是否答对 |
| `score` | number | 得分 0-100 |
| `answeredAt` | number | 服务端作答时间戳 |

**建议建复合索引**：`userId` + `answeredAt` 降序。
`getStats` 云函数按这两个字段查最近 7 天的记录。

### 权限设置

两个集合都设为「仅创建者可读写」或「所有用户可读，仅创建者可写」。

> ⚠️ **不要设成"所有用户可读写"**。
> 那样任何人都能改别人的数据。openid 是云开发自动注入的安全字段，
> 客户端无法伪造，所以按 openid 过滤是安全的。

## 四、部署云函数

在微信开发者工具里，**右键 `cloudfunctions/login` 文件夹** →
「上传并部署：云端安装依赖」。

依次部署三个：

| 目录 | 作用 | 依赖 |
|---|---|---|
| `cloudfunctions/login` | 静默登录换 openid | wx-server-sdk |
| `cloudfunctions/submitRecord` | 批量上报答题记录 | wx-server-sdk |
| `cloudfunctions/getStats` | 汇总学习数据 | wx-server-sdk |

**"云端安装依赖"和"本地安装依赖"选哪个？**

选**云端安装依赖**。这样不用在本机装 npm 包，
云端会自己装。个人项目用云端装最省事。

部署成功的标志：控制台 → 云函数列表里出现三个函数，状态为「正常」。

## 五、验证

在开发者工具的调试器 Console 面板里执行：

```js
getApp().globalData
```

如果看到：

```js
{
  openid: "o6_bmjrPTlm6_2sgVt7hMZOPfL2M",   // 有值
  examInfo: { ... }
}
```

说明云开发已经通了。

再看云开发控制台 →「数据库」→ `users` 集合，
应该已经有一条记录了。

如果 `openid` 是空的，看 Console 有没有报错：

- `cloud env not found` → 环境 ID 填错了，回第二步检查
- `FUNCTION_NOT_FOUND` → 云函数没部署成功，回第四步重新部署
- 没有任何报错但 openid 空 → 云开发面板里检查数据库权限

## 六、后续如何查看数据

部署完之后，你在控制台能看到：

### 用户量
云开发 → 数据库 → `users` 集合，看总条数

### 做题量
数据库 → `answers` 集合，按时间筛选看增长趋势

### 实时统计
云开发 → 云函数 → `getStats` → 点"云端测试"，
传 `{"openid": "你的openid"}` 能拿到聚合结果。

## 七、成本

个人项目在这个量级下，云开发基本不花钱：

| 项目 | 免费额度 | 说明 |
|---|---|---|
| 云数据库 | 一定额度内免费 | 存储按量计费，几万条记录约几毛钱 |
| 云函数 | 每月有免费调用次数 | 本项目只在用户进小程序时调一次 |
| 云存储 | 未使用 | 本项目没有上传文件 |

**500 个用户的数据量，预计年成本在几元以内。**
比任何自建方案（服务器最低配也要几十块/月）都便宜。

真超了额度会有邮件提醒，可以随时在控制台升配或降配。

## 八、要不要用 AI 判分

默认关闭。原因见 README「预留的 AI 接口」一节。

如果要接，三步：

### 1. 新建云函数

创建 `cloudfunctions/gradeByAI/index.js`，依赖同其他三个云函数。

### 2. Prompt 设计（这是关键）

判分质量取决于 Prompt，建议这样写：

```
你是教师资格证的阅卷老师。下面给你一份评分标准（若干评分点）和学生答案。

任务：逐条判断学生答案是否覆盖该评分点，给出判断和理由。

要求：
1. 只判断是否覆盖，不要自己重新评分
2. 每条返回 {"point": "评分点原文", "hit": 0或1, "reason": "覆盖原因"}
3. 最后给总分：命中数 / 评分点总数 × 100
4. 严格返回 JSON，不要有多余文字

评分标准：
{{points}}

学生答案：
{{userAnswer}}
```

### 3. 打开开关

`miniprogram/config/index.js`：

```js
const aiGrade = {
  enabled: true,
  apiKey: '你的 API Key'
};
```

> ⚠️ **API Key 不要提交到 Git**。
> 建议改成从云函数的环境变量读，不要放进代码仓库。

## 九、常见问题

**Q：个人主体能开通云开发吗？**
能。云开发对个人主体开放，有免费额度。

**Q：云函数超时了怎么办？**
本项目的 `core/cloud.js` 里所有调用都有 8 秒超时保护，
超时返回 null，前端自动降级到本地模式，不影响刷题。

**Q：数据库里的数据安全吗？**
openid 由云开发自动注入，客户端无法伪造，
所以别人改不了你的数据。设好权限就够了。

**Q：想看某个用户的数据？**
云开发控制台 → 数据库 → `users` 集合 → 按 `_openid` 筛选。

**Q：不想用云开发了怎么办？**
把 `config/index.js` 里的 `cloudEnv` 改回 `'your-env-id'` 即可，
全部功能退回纯本地模式，一行代码都不用动。
