## 阶段二：注册与信息填写（1 天）

### 小程序注册

1. 打开 https://mp.weixin.qq.com 注册小程序账号
   - 选**个人**主体（考证工具不属于需要资质的类目）
   - 邮箱、密码、身份证、微信验证
   - 注册后进入后台，"小程序后台"→"开发管理"→"开发设置"

2. 拿到 **AppID**
   - 复制到 `project.config.json`

3. 设置**类目**
   - 「设置」→「基本设置」→「服务类目」
   - 选「教育」→「教育工具」或相近项
   - ⚠️ **注意**：类目选错会导致后续无法开通流量主，
     而且某些类目需要额外资质（金融、医疗等）。考证刷题不属于这类。

4. 填写**名称和简介**
   - 名称：`教资刷题`
   - 简介：`教资刷题 免费题库 科目一 科目二 模拟考试 主观题判分 教师资格证笔试备考`
   - 具体理由见 [SEO配置清单.md](SEO配置清单.md)

### 微信认证（可选但建议做）

- 个人主体可以不做认证。
- 但**认证后能开通更多能力**（如部分流量主权限）。
- 认证费 300 元/年，个人开发者按需决定。
- 不认证也能上架，个人主体一样可以开通流量主。

## 阶段三：上传提交（1-3 天）

### 上传

1. 微信开发者工具点「上传」
   - 版本号填 `1.0.0`
   - 项目备注：`首个版本：科目一78题+科目二113题，含刷题/错题本/模考/数据统计/材料题离线判分`

2. 去微信公众平台「管理」→「版本管理」
   - 找到刚上传的版本，点「提交审核」
   - 填写：
     - 服务类目：与上面一致
     - 测试账号：不需要（无登录）
     - 功能页面：截图 + 说明

### 审核说明怎么写（提高通过率）

审核主要看两点：**是否涉及资质要求**、**是否有诱导分享/下载**。

建议填写：

```
功能说明：
本小程序为教师资格证笔试备考工具，提供以下功能：
1. 刷题：科目一（综合素质）、科目二（教育知识与能力）的单选与材料分析题练习
2. 错题本：自动收录未掌握的题目
3. 学习数据：本地统计做题量与正确率
4. 模考：限时答题练习

所有题目为按考纲整理的练习题，不含任何收费功能。
不涉及用户注册、支付、社交、位置等信息收集。
用户数据仅存储在本地，可随时在"我的-清除全部数据"中删除。
```

**被拒的常见原因**：
- 类别选错（选了需要资质的类目）
- 简介里有夸大宣传（"保过""官方"等词要避免）
- 有诱导分享文案
- 测试账号填了但实际不需要

### 审核通过后

- [ ] 立即发布（审核通过 ≠ 已发布，需要手动点发布）
- [ ] 发布后小程序才能被搜到

## 阶段四：冷启动（4-8 周）

### 目标

- 第 1 目标：**100 个累计独立访客**
- 第 2 目标：**500 个累计独立访客**（这是开流量主的门槛）

### 拉新手段（按性价比排序）

1. **微信搜一搜自然流量**
   - 靠 SEO 配置，见 [SEO配置清单.md](SEO配置清单.md)
   - 需要 4-8 周积累，不要指望立刻见效

2. **分享给同学和同事群**
   - 备考人群高度集中，同学群里发一次可能带来 20-50 UV
   - 分享按钮在每个页面右上角都已配置好
   - ⚠️ 不要用强制分享解锁功能（会违反微信规则被拒）

3. **知乎/小红书/B站发备考攻略**
   - 内容里带小程序名，让用户自己搜
   - 经验贴比工具介绍更容易被推荐
   - 见效慢但流量质量高

4. **考试季重点推广**
   - 笔试前 2 个月是流量高峰，此时加大推广力度
   - 报名期前 1 个月流量最集中

### 不要做的事

- ❌ 花钱买推广（个人跑不出 LTV）
- ❌ 做诱导分享/强制分享（违反规则，会被下架）
- ❌ 一次性铺多个赛道（相关性被稀释，搜索排名上不去）

## 阶段五：开通流量主（达到 500 UV 后）

### 申请条件

- 累计独立访客（UV）≥ 500
  - ⚠️ 微信开放社区和客服口径是 500，但广告官网文档部分仍写 1000，
    **以你后台实际显示为准**
- 个人主体可申请（不需要企业资质）
- 小程序已发布

### 开通步骤

1. 微信公众平台 →「广告与服务」→「流量主」→「申请开通」
2. 填写结算信息
   - 个人结算需要本人银行卡
   - 每月结算两次（15 日和 30 日左右）
3. 审核通过后，创建广告位：
   - **激励视频**：创建后拿到 `adunit-xxxxxxxx`
   - **插屏**：同上
   - **banner**：同上

4. 把广告位 ID 填进 `miniprogram/config/index.js`：

```js
const ad = {
  adsEnabled: true,              // ← 改这里
  rewardedVideoId: 'adunit-你的激励视频ID',
  interstitialId: 'adunit-你的插屏ID',
  bannerId: 'adunit-你的bannerID'
};
```

5. 重新上传版本，审核通过后发布

### 广告位置说明

代码里已经埋好三处，收益排序如下：

| 位置 | 广告类型 | eCPM 预估 | 说明 |
|---|---|---|---|
| 模考交卷后 | 激励视频 | 50-120 元 | 用户主动点"看广告解锁完整解析" |
| 首页底部 | banner | 8-20 元 | 滑到底才看到，不干扰刷题 |
| 模考结束页 | 插屏 | 15-40 元 | 用户最放松的时刻 |

**激励视频要放在用户主动点击的位置**。
无理由强弹会让用户反感，投诉多反而影响小程序权重。

### 预估收益（保守估计）

500 UV 的规模，按备考人群 eCPM 200 元算：

```
假设：500 用户 × 30 天活跃 × 每天 2 次激励视频 = 30000 次展示
eCPM 200 元 → 30000/1000 × 200 = 6000 元/月
```

⚠️ **这个数字是理论上限，实际通常是 1/3 到 1/5**。
真实预估约 1200-2000 元/月。
别拿这个去做职业规划，只当个零花钱。

## 阶段六：迭代

### 有真实用户后要做的第一件事

**收集反馈**。哪怕只有 20 个用户，也要认真看他们的意见。

微信后台 →「数据分析」→「自定义分析」可以看到：
- 哪些页面访问多、哪些页面没人用
- 用户从哪里进来（搜一搜 / 分享）
- 什么时段用户最活跃

### 版本迭代节奏建议

每 2-3 周一个小版本：

- 优先修用户反馈的 bug
- 其次补题库（题库量直接影响留存）
- 谨慎加新功能（加功能前问：用户真的会用吗）

### 简历上能写的量化数据

攒够数据后，简历里这样写比"做了一个小程序"强得多：

```
教师资格证备考小程序（个人项目，独立完成设计与开发）
· 自建 500+ 题教资题库（科目一/科目二，覆盖 9 个模块）
· 设计评分点命中算法实现材料题离线自动判分，
  避免依赖大模型接口，判分响应 < 10ms
· 基于微信云开发实现零成本部署（免服务器、免域名备案）
· 累计用户 XXX 人，次月留存 XX%，人均日做题 X 道
· 根据用户反馈迭代 X 个版本
```

数据没有就诚实写"当前累计用户 XX 人"，不要编。

## 一页纸总结

| 阶段 | 耗时 | 关键动作 | 容易踩的坑 |
|---|---|---|---|
| 工具里跑通 | 1 天 | 换 AppID、核对考试日期 | 未确认的考试日期没标"暂估"，用户会白跑考场 |
| 注册填信息 | 1 天 | 选对类目、填好简介 | 类目选错，后续开不了流量主 |
| 上传审核 | 1-3 天 | 写清功能说明 | 用"保过""官方"等词被拒 |
| 冷启动 | 4-8 周 | SEO + 同学群 | 期望值太高，两周没效果就放弃 |
| 开流量主 | 达到 500 UV | 填广告位 ID | 忘了重新上传版本 |
| 迭代 | 持续 | 收集反馈、补题库 | 只加功能不听反馈 |
