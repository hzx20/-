# 微信搜一搜 SEO 配置清单

个人开发者没有投放预算，搜一搜是唯一可持续的免费流量来源。
这份清单是照着抄就能执行的操作表。

**先说清楚能预期多少**：名称和简介改完后，3-7 天能看到搜索曝光变化；
但真正的行为数据（点击率、使用时长）要攒 4-8 周才体现。
不要改了两天没效果就换方向，那样永远攒不出数据。

---

## 一、搜索排名是怎么来的

搜一搜排序主要看三件事，了解了才知道该优化什么：

| 因子 | 含义 | 你能做什么 |
|---|---|---|
| 关键词相关性 | 名称、简介、页面标题里有没有用户搜的词 | **能直接优化** |
| 服务质量 | 用户搜索后是否点开、用了多久、是否收藏 | 产品要做对 |
| 用户使用情况 | 真实用户量、近期活跃度 | 冷启动阶段管不了，只能等 |

新小程序在第三项上必然吃亏，所以**前两周的唯一目标是把第一项做到极致**。

---

## 二、名称（最关键，改了要慎重）

### 定名原则

**不要起文艺名，直接起搜索词。**

用户在搜什么，他就叫什么。这不是取名，是选关键词。

用户实际会搜的词（按真实搜索习惯）：

```
教资刷题
教师资格证刷题
教资题库
教师资格证题库
科目一
科目一真题
综合素质
科目二
教育知识与能力
教资笔试
```

### 推荐方案

| 方案 | 名称 | 说明 |
|---|---|---|
| **推荐** | `教资刷题` | 4 字里含 2 个高频词（教资、刷题），且"刷题"是明确的功能词，用户看到就知道能干什么 |
| 备选 A | `教资题库` | 更垂直，但"题库"覆盖面比"刷题"窄，用户搜"教资刷题"的更多 |
| 备选 B | `教资笔试助手` | 关键词密度高，但"助手"二字占了 2 个字符，浪费字数 |
| **不推荐** | `上岸指南`、`考编小助手` | 用户搜的是具体词，不会搜文艺名 |

**命名约束**：

- 小程序名称上限 30 字符，别浪费在无关词上
- 名称里**必须**含"教资"或"教师资格证"，这是流量入口
- 不要带"我的""个人"等无搜索量的词
- **改名的代价**：微信规定改名有次数限制，且会影响部分搜索权重积累。
  所以第一版就要想清楚，改了尽量不再改。

## 三、简介（前 30 字是黄金位）

用户搜出来的列表页只显示简介的**前 20-30 字**，后面的看不到。

### 当前项目简介（可直接用）

```
教资刷题 免费题库 科目一 科目二 模拟考试 主观题判分 教师资格证笔试备考
```

前 30 字拆解（按用户搜索词排列）：

```
教资刷题  | 免费题库  | 科目一  | 科目二  | 模拟考试
```

把 5 个高频词塞进前 30 字，这是搜一搜简介的标准做法。

### 修改路径

1. 登录 https://mp.weixin.qq.com
2. 左侧「管理」→「基本设置」→「小程序信息」
3. 「简介」字段，替换为上面的文案

## 四、页面标题矩阵

微信会收录页面作为搜索结果，**每个页面的标题都要独立含关键词**。
当前代码里已经这样设置了：

| 页面 | 动态标题 | 设置位置 |
|---|---|---|
| 首页 | 教资刷题 | `pages/index/index.json` |
| 科目选择 | 科目一 章节 / 科目二 章节 | `pages/subject/subject.js` 里的 `wx.setNavigationBarTitle` |
| 刷题 | 科目一 · 职业理念 | 同上，practice.js 的 `wx.setNavigationBarTitle` |
| 模考 | 限时模考 | `pages/mock/mock.json` |
| 使用说明 | 使用说明 | `pages/guide/guide.json` |

**动态标题比写死更有优势**：用户搜"科目二 教育知识"时，
如果正好命中他练习过的模块，页面标题就正好是他要找的内容。
搜索匹配度会显著提高。

**建议进一步细化**，让标题带上具体知识点。把 `practice.js` 里的：

```js
wx.setNavigationBarTitle({
  title: (detail ? detail.shortTitle : '刷题') + ' · ' + (this._moduleName || '练习')
});
```

改成带上章节名：

```js
wx.setNavigationBarTitle({
  title: '教资' + detail.shortTitle.replace('科目', '') + ' ' + this._moduleName
});
// 效果：教资一 职业理念
```

## 五、分享文案（次要但成本低）

分享出去的卡片标题也是索引来源之一。
当前 `config/index.js` 里已配置：

```js
const share = {
  title: '教资刷题 - 教师资格证笔试免费题库',
  path: '/pages/index/index'
};
```

建议保持稳定，不要频繁改。分享文案里同样要有"教资""教师资格证""题库"。

## 六、sitemap 配置（已完成）

`miniprogram/sitemap.json` 设为全部允许收录：

```json
{
  "rules": [{ "action": "allow", "page": "*" }]
}
```

**注意**：默认模板里有一批 `disallow`，如果你没改，
页面根本进不了微信索引，等于放弃搜一搜。

## 七、上线后的 SEO 动作时间表

### 第 1 天：改完基础配置

- [ ] 名称改为「教资刷题」
- [ ] 简介按上面第三节的文案填好
- [ ] 确认 sitemap 是全 allow
- [ ] 提交审核（1-3 个工作日）

### 第 3-7 天：验证是否被收录

- [ ] 在微信搜一搜搜「教资刷题」，看能否搜到自己的小程序
- [ ] 搜「教资题库」「科目一」「教师资格证」交叉验证
- [ ] 搜不到的话，检查小程序是否已发布（开发版不会被收录）

### 第 2-4 周：内容补齐

- [ ] 扩题库到 500+ 题（题库量直接影响"服务质量"因子）
- [ ] 补齐模考、错题本的完整流程
- [ ] 把 examIds 里过期的场次日期更新

### 第 4-8 周：开始有自然流量

到这一步应该有稳定的搜索曝光了。看后台数据：
- 「微信搜一搜」的访问来源占比
- 搜索进来的用户次月留存

留存比访问量重要得多——搜进来刷两题就走等于没用。

## 八、不要做的事

- **不要在简介里堆无关热词**：写"考研 计算机 会计 公务员"想覆盖多个赛道，
  结果相关性被稀释，搜什么排名都上不去。砍到单点才有排名。
- **不要频繁改名改简介**：每次改动都会重置一部分权重积累。
- **不要买"小程序推广"**：个人开发者跑不动付费投放的 LTV 测算，
  而且会把预算投给泛人群，转化极差。
- **不要在标题里用特殊符号堆砌**：如「教资刷题 || 题库 || 真题」，
  微信会判定为标题堆砌。
